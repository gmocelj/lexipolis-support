How to play

Rules for 2–10 players, on one device or several. No internet needed.

Start a game

On one device: add 2–10 players and take turns writing. Pass the device to the next player; earlier answers stay hidden.

On several devices: connect everyone to the same Wi-Fi or hotspot. One player hosts; others join from the list, by QR code or manual entry. iPhone, iPad and Android can play together.

Choose 3–8 categories, rounds, available letters, time and how rounds end. Each drawn letter is used once per game.

Your own categories

Custom categories are prepared for the next app release. If they are not on your phone yet, they will arrive in an update.

In game setup, open My categories and add a name, such as Football players or Car brands. Names can contain up to 32 characters. Categories are saved only on this device and can be reused or renamed.

A game has 3–8 categories in total, built-in and custom combined. Deselecting a category only removes it from the current selection. Delete permanently removes it from the saved list after confirmation; if fewer than three remain selected, choose more before starting.

Custom categories have no term database. Empty answers and wrong starting letters earn 0; other answers go to a vote. The same normalized text counts as the same answer, but different nicknames or names are not automatically recognized as one person. Surnames are not extracted automatically: the group can name a category Football players — surname.

On several devices, the host enters the names and everyone sees them without translation. Renaming or deleting a saved category does not change a game already in progress. Network play with this feature requires a newer app version on every phone.

Writing and ending a round

Write an answer in each category starting with the drawn letter. An empty field earns 0. The app asks for confirmation if you finish with empty fields.

In timer mode, writing ends when time runs out. On one device, finishing your turn early passes the device on; the next player still gets their full time.

In Stop mode on several devices, any player can call Stop: a 3-second countdown runs before answers lock. On one device, the selected rule determines whether Stop ends only your turn or the first player’s time becomes everyone’s limit.

Answer symbols

In the database

The answer is in the database and matches the letter. It can earn 20, 10 or 5 points.

Waiting for a vote

Other players decide whether the answer fits the category.

Accepted

The players accepted the answer.

Rejected

The players rejected the answer. It earns 0 points.

Wrong letter

The answer starts with the wrong letter. It earns 0 without a vote.

Empty

No answer was entered. It earns 0 without a vote.

Checking and voting

Countries, cities, rivers, mountains, lakes, plants and animals are checked against the built-in database. An unknown answer on the right letter goes to a vote; it is not automatically rejected. Objects always go to a vote.

On several devices, everyone except the answer’s author votes. The majority of votes cast decides; a tie or no votes means acceptance. Missing votes do not count. Voting lasts 20 seconds; with two players, the opponent decides.

On one device, the group discusses the answer and accepts or rejects it on the card.

How points work

Each category is scored separately. Answers found in the database and answers accepted by a vote follow the same scoring rules.

Different names for the same database entry can count as the same answer. After each round, see answers, points and running totals. After the last round, see the final ranking; equal totals share a place.

The only valid answer in the category
10
A valid answer nobody else gave, with other valid answers present
5

0

Examples

Letter S, country: Ana — Serbia; nobody else has a valid answer. Ana earns 20.

Ana — Serbia; Bojan — Slovenia. Both earn 10.

Ana and Bojan — Serbia; Mina — Slovenia. Ana and Bojan earn 5 each, Mina earns 10.

Language and starting letters

Change the app language in Settings. Choose the game language before starting; everyone answers in that language regardless of their interface language.

Letter matching follows the game language, including supported scripts, accents and alternative names. In English, leading articles can be omitted: The Gambia counts for G. In the shared BCMS game, cacak matches Čačak and counts for Č, not C; Lj, Nj and Dž are separate letters.

Connection help

If a game is missing, check that everyone uses the same Wi-Fi, allow Local Network access on iPhone, or try a hotspot. QR scanning needs camera permission; the list and manual entry work without it.

These instructions work offline. Opening them does not pause a running round; check the rules before playing or between rounds.
